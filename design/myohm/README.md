# Myohm visual identity

`myohm-editable.svg` is the editable master logo (2026-09-17). Preserve this file as the master; create separate derived assets for web icons or PCB silkscreen.

- Transparent background, 1440 × 520 viewBox.
- Vector paths and a circle; no external fonts or embedded raster images.
- Primary color: `#092568`.
- Five independently grouped letters; retain their geometry and proportions.

PCB derivatives require a monochrome conversion with stroke dimensions verified at manufacturing scale, followed by DRC and visual inspection. The current board still uses its reviewed text wordmark.
